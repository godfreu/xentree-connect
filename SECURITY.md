# Security Policy

PT Global Otomat Digital takes security vulnerabilities seriously.

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability
If you discover a security vulnerability in Xentree Connect:
1. Please do NOT open a public GitHub issue.
2. Email full technical details and reproduction steps to **security@xentree.ai** (or **security@god.co.id**).
3. Our engineering and security team will acknowledge receipt within 24 business hours and coordinate remediation.
